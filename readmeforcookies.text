In Express, signed cookies are cookies that are digitally signed so the server can detect if someone has tampered with them.

👉 Normal cookie = can be modified by user
👉 Signed cookie = modification is detected (becomes invalid)
How it works (simple idea)

When you sign a cookie:

Express adds a signature using a secret key
When the cookie comes back, Express verifies the signature
If changed → value becomes false (invalid)
